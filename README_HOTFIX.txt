но не совпадать с точными VBMLRule-обработчиками VKBottle.

- нормализуются emoji variation selectors;
- поддерживается возможный префикс упоминания сообщества в беседе;
- сохранены старые точные обработчики и команды;
- динамическая кнопка открытия предложения тоже поддержана.

Установка:
1. Скопировать папку systems поверх корня репозитория с заменой systems/admin.py.
2. Commit -> Push origin.
3. Перезапустить бота на BotHost.
4. Открыть /админ и проверить кнопки.
