ОПЫТ И ФРАКЦИИ — АКТУАЛЬНАЯ СБОРКА

В админской беседе: /админ → «Управление игроком» → ID персонажа.

«Опыт игрока»:
— «Выдать XP» — добавить указанное количество;
— «Списать XP» — убрать указанное количество, без ухода ниже нуля;
— «Установить XP» — задать общий опыт, включая 0.
Вводите целое число. «К игроку» отменяет ввод.
Изменение XP не меняет карьерную должность и уровень: автоматическая
формула повышения уровня за XP в текущем боте отсутствует.

«Фракция игрока» → «Изменить фракцию»:
Директория, HELIOS Dynamics, Орден Завесы, Культ или без фракции.
При смене сбрасывается фракционный ранг. Новый ранг назначается
существующими кнопками повышения и понижения в этом же разделе.
Повторный выбор текущей фракции не сбрасывает ранг.

Доступ: администратор, старший администратор, владелец.
Модератор и обычный игрок не могут изменять XP и фракцию.
Эти действия работают только в настроенной админской беседе.
В журнале сохраняются администратор, персонаж, время, старое и новое
значения. Запись изменения и журнала выполняется одной транзакцией.
Бот не отправляет отдельные уведомления игрокам об этих изменениях.

УСТАНОВКА ПОЗЖЕ
admin.zip — накопительный патч поверх существующего проекта, включая
предыдущие изменения регистрации, меню, перемещения и боевой системы.
Отдельно устанавливать character.zip и предыдущие архивы не требуется.
Остановите бота, сохраните резервную копию кода и актуальной БД.
Распакуйте содержимое рядом с main.py с заменой файлов и объединением папок.
Сохраните существующие .env, БД и остальные изображения магазина.
Архив не содержит токен, БД или вложенные ZIP. Схему БД менять не требуется.
Для этой сборки главная инструкция — INSTALL_ADMIN.txt.
INSTALL_ONBOARDING.txt и INSTALL_RP_QUIET.txt описывают предыдущие функции.

В GitHub ничего не опубликовано, сервер не обновлён.
Автоматические проверки выполняются на временной БД без доступа к ВК.
После установки проверьте действия на тестовом персонаже в админской беседе.
Известное прежнее ограничение: панель дуэли не обновляется в фоне
при истечении времени ожидания. Эта сборка его не меняет.
