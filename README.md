# ECHOES OF THE RIFT — стабилизация перед обновлением

Патч для проекта из присланного архива. Игровые каталоги, цены, зарплаты,
изображения и лор не изменены. Новые игровые механики не добавлены.

## Установка

См. INSTALL_STABILITY.txt. Архив накладывается на существующий проект.
База, .env, изображения и attachment_cache.json в патч не входят.

## Что исправлено

- Зарплата: проверка срока и начисление выполняются одной транзакцией.
- Магазин: проверка баланса, списание и выдача предмета выполняются вместе.
- Аренда: проверка периода, списание и дата платежа выполняются вместе.
- Инвентарь: списание и передача защищены от одновременных запросов и
  частичного выполнения; передача требует одобренных персонажей.
- Задания: повторная выдача, отправка отчёта, принятие и отклонение
  проверяют актуальный статус внутри операции БД.
- Удаление своего персонажа: подтверждение/отмена в ЛС, срок 5 минут,
  проверка ID удаляемого персонажа. Баланс возвращается к 1500 CR,
  XP к 0, уровень к 1 — это сохранённое правило проекта.
- Черновик квенты сохраняется в SQLite после каждого шага. Кнопка
  «Создать квенту» продолжает сохранённый шаг; «Назад» и «Начать»
  приостанавливают ввод; «Начать заново» удаляет черновик.
- Повторное завершение формы не создаёт вторую квенту.
- Сообщения одного игрока обрабатываются последовательно.
- Финансовые админ-кнопки и /деньги, /снятьденьги используют одну
  операцию с проверкой роли и записью в журнал в той же транзакции.
- Старые административные маршруты вынесены из main.py в
  systems/legacy_admin.py; форма персонажа находится в systems/characters.py.
- Перед первой миграцией этой версии создаётся проверенная резервная
  копия SQLite в backups рядом с рабочей базой. Повторная миграция
  не перезаписывает данные или пользовательские настройки локаций.
- Настройки .env загружаются до выбора файла БД. Порядок выбора:
  DATABASE_PATH, DB_PATH, DATA_DIR/database.db, существующая /app/data,
  затем database.db проекта. Кэш фото хранится в постоянном каталоге.

## Проверки

python -m pip install -r requirements.txt
python -m unittest discover -s tests -v

Тесты работают с временными базами и тестовым токеном; сеть VK подменена.
В комплекте 26 проверок: конкуренция запросов, откат при ошибках,
переходы заданий, права, промокод, удаление, черновики и обработка сообщений.

Проверено на Python 3.12 / Windows с vkbottle 4.10.0, aiosqlite 0.22.1,
python-dotenv 1.2.4, loguru 0.7.3. Запуск в Linux/BotHost и реальные
события VK нужно проверить после установки. Отдельно проверена миграция
копии присланной базы: исходные записи всех 7 таблиц сохранены; создано
18 таблиц, PRAGMA integrity_check = ok, повторная миграция успешна.

## Эксплуатация

Запускайте один экземпляр бота на одну рабочую БД. Временные диалоги
админ-панели, переводов и магазина после рестарта открываются заново;
черновики квент сохраняются. Автокопия перед миграцией не заменяет
регулярные резервные копии работающей игры. Подтверждение удаления
намеренно не сохраняется при перезапуске — его нужно запросить заново.
