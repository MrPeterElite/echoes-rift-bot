# ECHOES OF THE RIFT [TRP] — full modular build

## Структура

```text
main.py
database.py
quests.json
data/quests.json
systems/
  __init__.py
  characters.py
  careers.py
  economy.py
  locations.py
  housing.py
  factions.py
  rp.py
```

## Что вынесено

- `systems/characters.py` — квенты, архив, создание персонажа.
- `systems/careers.py` — карьера, должность, зарплата.
- `systems/economy.py` — `/богачи`, `/перевести`.
- `systems/locations.py` — `/локации`, `/гдея`, `/перейти`.
- `systems/housing.py` — каюты и аренда.
- `systems/factions.py` — отображение фракций.
- `systems/rp.py` — `/me`, `/do`, `/say`, `/try`.

## Важно

`.env` и `database.db` не включены в архив специально.
Оставь свои текущие `.env` и `database.db` в папке проекта.

## Запуск

```bash
python main.py
```


## Исправление RP-команд

RP-команды теперь обрабатываются через `router_handler`, поэтому работают с длинным текстом:

```text
/me проверяет панель управления
/do В коридоре мигает аварийный свет
/say Всем отойти от шлюза
/try взломать терминал доступа
```

Магазин показывает один товар с фотографией и кнопками: Предыдущий, Купить, Следующий, Категории. Команда `/купить 3` покупает 3 экземпляра текущего открытого товара. Использование еды через `/использовать номер` отправляет случайное RP-сообщение.
