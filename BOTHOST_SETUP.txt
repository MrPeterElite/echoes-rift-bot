Настройка BotHost для этой сборки

Главный файл: main.py. Исходный проект рассчитан на Python 3.11+.
Локальные проверки патча выполнены на Python 3.12.
Зависимости: requirements.txt.

VK_TOKEN — токен сообщества (также поддержан BOT_TOKEN).
ADMIN_CHAT_ID — peer_id административной беседы.
BOT_OWNER_ID — числовой VK ID владельца.
DATABASE_PATH/DB_PATH — явный путь к существующей БД, имеет высший приоритет.
DATA_DIR — постоянный каталог, используется при отсутствии явного пути БД.

Если явный путь и DATA_DIR не заданы, используется существующая /app/data,
а локально — database.db рядом с main.py. Не меняйте путь при обновлении,
если база уже работает. Лог резервного копирования покажет выбранный каталог.

Установка и проверка: INSTALL_STABILITY.txt.
